Jotto Solver

A Java-based solver for the word game Jotto using information theory.

Source Code ↗

About

I was introduced to Jotto in my CS course and took an immediate liking to it. It was like Wordle, but instead of knowing the positions of letters, you only know how many letters are shared between your guess and the secret word. I'd learned about information theory before, and this seemed like the perfect place to apply it. On average, the solver takes around 7.39 guesses to arrive at the correct word, which beats out most human players.

Approach

In Jotto, each guess is given a number from 0-5 (assuming 5-letter words) to indicate how many letters are shared between the guess and secret word. If your guess and the secret word both have multiple of the same letter, then it gets counted multiple times. The approach I took for applying information theory to this was to try and maximize the entropy gained from each guess by splitting the solution space between each possible reponse to the guess (0-5), which should lead to an exponential decrease of the solution space. For this project, I used a dictionary of 5757 5-letter words, which for context is larger than the number of potential solutions in Wordle but smaller than the number of guesses it allows. The solver repeatedly iterates through the full dictionary to generate guesses each turn, choosing the guess with the highest entropy.
