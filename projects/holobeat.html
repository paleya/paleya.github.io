HoloBeat

A Java-based neural network that automatically plays the fishing minigame in Holocure.

Source Code ↗

About

"Holocure - Save the Fans!" is a game available for free on Steam. As part of the game, there are a collection of minigames that can be played for resources and currency. In particular, the fishing minigame is a rhythm-based game where you time different keypresses as they show up on screen. This bot automatically plays that game by taking images of the game continuously and evaluating when to press each key through a basic convolutional neural network.

Approach

The primary challenge in this project was detecting when to press certain keys in a game UI that is highly variable, whether due to it being day/night in the game, raining, or other factors. To do this, I made a basic convolutional neural network (CNN) to interpret a screenshot of the game and determine which, if any, keys need to be pressed. By repeating this process in real time, the bot can play the fishing minigame successfully and repeatedly without any human input.
